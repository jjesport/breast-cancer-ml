# Breast Cancer Classification using Machine Learning

![Banner](banner.png)

## Authors
Sebastian Andres Baldovino, Juan Jose Espinosa

## Objective
Develop a machine learning model capable of classifying breast cancer tumors as malignant or benign using diagnostic data.

## Dataset
Breast Cancer Wisconsin Dataset

Download link:
https://www.kaggle.com/datasets/uciml/breast-cancer-wisconsin-data

## Models
Decision Tree, Random Forest, Support Vector Machine (SVM), K-Means, DBSCAN, Deep Neural Networks, GridSearchCV, Cross Validation, StandardScaler, PCA, Confusion Matrix, Classification Report
